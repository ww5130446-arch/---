# أريليا — مشروع Godot 4

دي نسخة أولية مستقلة داخل مجلد Godot في فرع GitHub اسمه `arielia-godot-start`، من غير ما نغيّر ملفات الفرع الأساسي.

## الموجود
- مشهد ثلاثي الأبعاد بمحرك Godot 4 وإعداد Compatibility المناسب للموبايل.
- أرض كبيرة، نهر بصري، طريق، أشجار وصخور وقرية صغيرة.
- شخصية مؤقتة بمنظور الشخص الثالث وحركة وقفز.
- أزرار لمس للحركة والجري والقفز والهجوم والحفظ، وسحب لتدوير الكاميرا.
- مخلوقات برية تتحرك وتتوقف، ودورة نهار/ليل، وحفظ محلي.

## تشغيله
1. نزّل Godot 4.x من الموقع الرسمي: https://godotengine.org/download/
2. افتح Godot ثم Import واختر `Godot/project.godot`.
3. شغّل المشروع من داخل المحرك.

## حدود مهمة
دي بداية تطوير وليست اللعبة النهائية. المجسمات مؤقتة، والنهر لا يحتوي سباحة، ولا توجد APK حتى الآن. لم يتم تشغيل المحرك هنا، لذا يلزم اختبار المشروع داخل Godot قبل اعتباره خاليًا من الأخطاء. لا يحتاج المشروع إلى OpenAI API key؛ إضافة API لن تفيد لعبة أوفلاين وقد تتطلب اتصالًا وتكلفة.
